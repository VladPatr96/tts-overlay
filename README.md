# Озвучка выделенного — оверлей для Windows

Плавающий оверлей поверх всех окон: выделяешь текст в любой программе, жмёшь горячую клавишу — текст озвучивается. И наоборот: держишь клавишу и говоришь — оверлей распознаёт речь. Движок на выбор: облачный (Edge TTS, Яндекс SpeechKit, OpenRouter) или локальный (Silero v5, SAPI 5, Piper). PowerShell-скрипт с модулями рядом, без установщиков и сборки.

Возможности: шесть источников синтеза, распознавание голоса (OpenRouter или локальный faster-whisper), разбор чисел и дат словами, словарь произношения (SSML 1.1), учёт затрат в рублях и долларах, кэш озвученного, запасной движок, когда основной не отвечает.

## Как пользоваться

| Действие | Как |
| --- | --- |
| Озвучить выделенное в любой программе | выделить текст → `Ctrl+Alt+S` |
| Озвучить буфер обмена | `Ctrl+Alt+D` |
| Надиктовать текст голосом | зажать `Ctrl+Alt+V` → сказать → отпустить; текст появится в оверлее и в буфере обмена |
| Стоп | `Ctrl+Alt+X` или кнопка `⏹` |
| Пауза / продолжить | кнопка `⏸` |
| Настройки (движок, голос, скорость) | кнопка `⚙` |
| Свернуть в трей / вернуть | `✕` в углу, двойной клик по значку в трее |
| Перетащить оверлей | тянуть за заголовок «Озвучка» |

Горячие клавиши не отбирают фокус у программы, поэтому выделение остаётся на месте. Буфер обмена после перехвата восстанавливается.

## Что нужно

| Для | Что требуется |
| --- | --- |
| Само приложение | Windows 10/11 и PowerShell 7 (`pwsh`) — всё, что нужно для Яндекса, OpenRouter и SAPI 5 |
| Edge TTS | Python 3.10+ с `pip install edge-tts miniaudio` |
| Silero v5 | Python 3.10+ с `torch` (CPU), `omegaconf`, `silero` и модель `v5_ru.pt` в папке `silero/` |
| Piper | бинарник в `piper/app/` и голоса `.onnx` в `piper/voices/` |
| Распознавание голоса | Python 3.10+ с `sounddevice` (запись с микрофона) и `faster-whisper` (локальное распознавание) |

Модели и бинарники в репозиторий не входят — их нужно положить самому (см. «Источники синтеза»).

## Запуск

- Автозапуск при входе в Windows: `pwsh -File install.ps1` (создаёт ярлык в автозапуске и запускает оверлей).
- Ярлык на рабочем столе: `pwsh -File install.ps1 -Desktop`.
- Запустить сейчас, без ярлыков: `start.cmd`.
- Остановить: `pwsh -File stop-overlay.ps1`.
- Убрать из автозапуска: `pwsh -File install.ps1 -Remove`.

Настройки лежат в `config.json` рядом со скриптом. Шаблон без ключей — `config.example.json`: скопируй его и впиши ключ Яндекса.

## Настройки

Всё лежит в `config.json` рядом со скриптом:

| Поле | Смысл |
| --- | --- |
| `provider` | `edge` (Edge TTS), `yandex` (Яндекс SpeechKit), `openrouter` (модели OpenRouter), `silero`, `sapi`, `piper` — последние три работают локально и бесплатно |
| `yandexKey` | API-ключ Яндекс Cloud (`Authorization: Api-Key …`), только для `provider = yandex` |
| `yandexVoice` | голос Яндекс: `alena`, `jane`, `omazh`, `marina`, `filipp`, `ermil`, `zahar`, `madirus` |
| `yandexLang` | язык синтеза, по умолчанию `ru-RU` |
| `yandexRubPer1kChars` | тариф Яндекса за 1000 символов (1,342 ₽ с НДС) |
| `yandexBalanceStart` | если указать свой баланс Яндекса в рублях, видно «осталось ≈ …» |
| `piperExe`, `piperVoicesDir`, `piperVoice` | путь к движку Piper, папка с голосами и выбранный голос |
| `edgeVoice` | голос Edge TTS: `ru-RU-DmitryNeural`, `ru-RU-SvetlanaNeural` |
| `edgeRate`, `edgePitch` | темп и тон Edge: `-10%`, `+4Hz` |
| `sapiVoice` | голос SAPI 5: `Microsoft Irina Desktop - Russian` (по умолчанию), `Microsoft Zira Desktop`, `Microsoft David Desktop` |
| `sileroPython`, `sileroWorkerScript`, `sileroSpeaker` | Python для Silero, путь к воркеру и голос (`aidar`, `baya`, `kseniya`, `xenia`, `eugene`) |
| `model` | TTS-модель OpenRouter (для `provider = openrouter`) |
| `voice` | голос модели OpenRouter (у бесплатной Fish Audio — только `alloy`) |
| `speed` | скорость воспроизведения (плеер, без повторной оплаты) |
| `maxCharsPerRequest` | размер куска текста в одном запросе: `4000` — по границам предложений, `0` — не дробить вовсе |
| `cacheMaxMB` | предел кэша озвученного (по умолчанию 200 МБ) |
| `speakSelectionHotkey`, `speakClipboardHotkey`, `stopHotkey` | горячие клавиши, формат `Ctrl+Alt+S` |
| `sttProvider` | движок распознавания речи: `openrouter` (облако) или `whisper` (локально, офлайн) |
| `sttModel` | модель распознавания в OpenRouter, например `google/gemini-3.5-flash-lite` |
| `sttWhisperModel` | модель faster-whisper: `tiny`, `base`, `small`, `medium`, `large-v3` |
| `sttLang` | язык распознавания, по умолчанию `ru` |
| `sttHotkey` | горячая клавиша диктовки, по умолчанию `Ctrl+Alt+V` |
| `sttMaxSeconds` | сколько секунд максимум можно держать клавишу, по умолчанию 60 |
| `sttWorkerScript` | путь к воркеру распознавания (`stt/stt-worker.py`) |
| `sttPrompt` | промпт для OpenRouter: как просить расшифровку |

Провайдер, модель, голос и скорость меняются и из панели `⚙` — выбор сохраняется в `config.json`.

Ключ OpenRouter (для `provider = openrouter`) берётся из подключения OpenCode (`~/.local/share/opencode/auth.json`, провайдер `openrouter`); можно переопределить переменной `OPENROUTER_API_KEY`.

## Источники синтеза

- **Яндекс SpeechKit** — 8 голосов на текущем ключе, русские, звучат естественно; тариф 1 342 ₽ за 1 млн символов.
- **Edge TTS (бесплатно)** — неофициальный эндпоинт Microsoft, нейросетевые русские голоса: `ru-RU-DmitryNeural` и `ru-RU-SvetlanaNeural`. Реализация — `edge\edge-worker.py` на питоне (`pip install edge-tts miniaudio` + свежие файлы DRM из `edge\`, см. `NOTICE.md`). Сервис Microsoft бывает капризным: часть запросов заканчивается «нет звука», поэтому воркер делает две попытки параллельно, повторяет до трёх раз и на каждый заранее тратит не больше 14 с. Звук приходит mp3, воркер декодирует его через miniaudio и отдаёт WAV. Если сервис не отвечает, виджет сам уходит на запасной движок (см. «Запасной путь»).
- **Silero v5 (локально, бесплатно)** — пять русских голосов: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`. Модель `v5_ru.pt` (138 МБ) лежит в `silero\`, скрипт `silero\silero-worker.py` держит её в памяти: первый запрос ~20 с (загрузка), дальше ~1 с. Нужны Python и `torch` (уже установлены):
  ```
  python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
  python -m pip install omegaconf
  python -m pip install silero --no-deps
  ```
- **SAPI 5 (встроенный в Windows, бесплатно)** — голоса системы: `Microsoft Irina Desktop - Russian` (русский, по умолчанию), `Microsoft Zira Desktop`, `Microsoft David Desktop`. Голос роботный, зато работает мгновенно и без интернета. Синтез идёт в отдельном процессе (`sapi\sapi-speak.ps1`).
- **Piper (локально, бесплатно)** — движок в `piper\app\piper\piper.exe`, голоса в `piper\voices\`. Русских всего четыре: `ru_RU-dmitri-medium`, `ru_RU-irina-medium`, `ru_RU-denis-medium`, `ru_RU-ruslan-medium` — качество заметно слабее, чем у Silero и Яндекса. Новый голос добавляется двумя файлами в `piper\voices\`: `имя.onnx` и `имя.onnx.json` (брать с [HuggingFace](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU)).
- **OpenRouter**: у бесплатной `fish-audio/s2.1-pro-free:free` голос ровно один (`alloy`, 0 ₽). Остальные — платные, цена за 1000 символов: **Google Gemini TTS — $0.0005** (30 голосов, мультиязычный, читает русский; отдаёт только PCM — виджет сам заворачивает его в WAV), Microsoft MAI 2.1 Flash — $0.015 (97 голосов, включая `ru-RU-Masha`, `ru-RU-Lev`, `ru-RU-Harper`, `ru-RU-Grant`), ElevenLabs multilingual — $0.04 (21 голос), Sesame CSM-1B — $0.007, Qwen/HeyGen/Mistral/MiniMax/Deepgram/xAI Grok — $0.004–0.06, Kokoro-82M — $0.0006 (54 голоса, но русского нет). Список моделей с ценами подтягивается в панель `⚙`.
- **Бесплатные облачные**: `bytedance-seed/seed-audio-1-0` (0 ₽, один голос) и `fish-audio/s2.1-pro-free:free` (0 ₽, голос `alloy`).

### Запасной путь

Запасной путь срабатывает в двух случаях.

**Латиница в тексте.** Локальные русские модели (Silero, Piper, SAPI) не умеют читать английские слова. Если в тексте есть латиница, виджет сам озвучивает его через Яндекс (`fallback: в тексте есть английские слова` в логе), а в счётчике такая трактовка идёт по строке «Яндекс/… (запасной)». Отключается флагом `fallbackToYandex = false`.

**Движок не ответил.** Edge TTS и другие облачные движки иногда не отвечают. Тогда виджет не молчит, а переключается на Яндекс и озвучивает текст им: в статусе видно «Движок не ответил — озвучиваю через Яндекс». Синтез идёт заново, поэтому задержка — это время неудачной попытки (для Edge обычно 10–15 с).

## Произношение: стандарты и настройки

За основу взяты **SSML 1.1 (W3C)** — стандарт разметки для синтеза речи:
`<sub alias>` (произношение), `<phoneme alphabet="ipa">` (фонетика), `<say-as>` (числа и буквы), `<break>` (паузы), `<prosody>` (темп и тон), `<emphasis>` (акценты), `<lang xml:lang>` (смена языка).

**Словарь произношения** — файл `pronounce.json` рядом со скриптом (создаётся автоматически с базовыми записями). Формат — как у лексиконов CMUdict/LEXICON:

```json
{
  "API": "АПИ",
  "OpenRouter": "Опен Роутер",
  "т.е.": "то есть",
  "SSD": "эс эс ди"
}
```

Плюс поддерживается текстовый формат `pronounce.lexicon` — «слово<TAB>произношение» (по одному в строке, `#` — комментарий). Оба файла читаются при старте; кнопка «Словарь произношения» в панели `⚙` открывает `pronounce.json` в блокноте.

Значения со специальными префиксами работают в режиме SSML (движок Edge):
- `ipa:ˈa.pɪ` — произнести по фонетике (тег `<phoneme>`);
- `en:Open Router` — прочитать по-английски (тег `<sub alias>`).

**Числа, даты и деньги** читаются словами (галка в панели `⚙`):
- `1500` → «тысяча пятьсот», `2 500 000` → «два миллиона пятьсот тысяч»;
- `16.10.2026` → «шестнадцатого октября две тысячи двадцать шестого года», `31.12.2025` → «тридцать первого декабря…»;
- `12.5%` → «двенадцать целых пять десятых процентов», `1.5` → «одна целая пять десятых»;
- `$45` → «сорок пять долларов», `1500 рублей` → «тысяча пятьсот рублей»;
- версии вида `1.2.3` не трогаются.

**Интонация** — по знакам препинания в самом тексте: `…` даёт паузу, `—` и запятая — перепад тона, `**жирный**` (для Edge) превращается в `<emphasis>`, английские слова — в `<lang xml:lang="en-US">`.

**Живость по движкам:**
- Яндекс: `yandexSpeed` (0.1–3, по умолчанию 1) и `yandexEmotion` (`good` — работает у голосов alena / jane / marina; если голос такую роль не знает, виджет повторит запрос без эмоции);
- Edge: `edgeRate` (например `-10%`) и `edgePitch` (`+4Hz`);
- Silero: `sileroAccent` (автоударения) и `sileroYo` (читать «ё»).

## Распознавание речи

Оверлей умеет не только озвучивать, но и распознавать. Зажмите `Ctrl+Alt+V` (или свою клавишу из `sttHotkey`), скажите что-нибудь и отпустите — запись остановится, текст расшифруется, появится в оверлее и ляжет в буфер обмена. Движок выбирается в панели `⚙` («Распознавание речи») и запоминается в `config.json`.

Запись идёт в WAV 16 кГц, моно, 16 бит — такой файл понимают оба движка.

**OpenRouter (облако)** — тот же ключ, что и для синтеза; аудио уходит в base64 в `POST /api/v1/chat/completions` с типом содержимого `input_audio`. Замеры на 60 секундах русской речи:

| Модель | $/мин | Отклик | Замечание |
| --- | --- | --- | --- |
| `google/gemini-3.5-flash-lite` | 0,0008 | 4,3 с | по умолчанию |
| `openai/gpt-audio-mini` | 0,0007 | 4,0 с | тоже хорош |
| `mistralai/voxtral-small-24b-2507` | ~0,0008 | — | специализированная модель распознавания, умеет 429 от провайдера |
| `google/gemini-3.8-flash` | 0,0050 | 10,5 с | точная, но дороже |

**faster-whisper (локально, офлайн)** — модель грузится один раз и живёт в воркере: `base` — 3 с на 8 секунд звука, `small` — 12 с, `large-v3` — 62 с (на CPU). По умолчанию `base`; модель качается в кэш Hugging Face сама при первом запуске, дальше работает без интернета.

Что нужно поставить для диктовки:

```
python -m pip install sounddevice faster-whisper
```

Если `sounddevice` не установлен, всё остальное приложение работает как прежде — воркер распознавания просто не стартует, а в логе будет `stt: воркер не запустился`.

## Учёт затрат

Под оверлеем всегда висит строка с расходами **по тому провайдеру, который сейчас выбран**:

- «Сегодня: N симв. · сумма» — по активному источнику;
- «Выделено: N симв. ≈ сумма» — по последнему выделению, до озвучки;
- остаток OpenRouter (в долларах и в рублях) — из `/api/v1/credits`, обновляется раз в 10 минут;
- курс доллара — с сайта ЦБ, обновляется раз в сутки.

Данные лежат в `usage.json`: счётчики разделены по провайдеру и модели (`yandex|filipp`, `piper|ru_RU-dmitri-medium`, `openrouter|модель|голос`), поэтому переключение источника не смешивает расходы. Для Яндекса остаток счёта программно недоступен (у ключа только SpeechKit-скоупы) — его можно вписать руками в `yandexBalanceStart`, тогда видно «осталось ≈ …».

Распознавание речи считается отдельно (`usage.json` → `stt`): в панели `⚙` видно, сколько секунд звука распознано сегодня и во сколько это обошлось — облачные движки тарифицируются по длине звука, локальный faster-whisper стоит 0 ₽.

## Что под капотом

- `tts-overlay.ps1` — всё приложение: WPF-оконка, глобальные хоткеи (`RegisterHotKey`), перехват выделения (`Ctrl+C` + проверка номера буфера, чтобы не озвучивать старое), очередь кусков, воспроизведение через `MediaPlayer`, трей, кэш, счётчики затрат.
- `lib-core.ps1` — лог, конфиг и ключ OpenRouter. Остальные части главного скрипта выносятся в `lib-*.ps1` по слоям (`docs/adr/0001-module-layout.md`).
- `lib-usage.ps1` — учёт затрат, баланс OpenRouter и курс ЦБ.
- `lib-providers.ps1` — движки синтеза: запросы, запуск воркеров, голоса, форматы звука.
- `lib-playback.ps1` — очередь кусков, кэш и воспроизведение.
- `lib-text.ps1` — подготовка текста перед синтезом: числа, даты, деньги, дроби, словарь произношения, сборка SSML.
- `edge/edge-worker.py` — воркер Edge TTS (Python): DRM-токен, параллельные попытки, декодирование mp3 в WAV.
- `silero/silero-worker.py` — воркер Silero: модель в памяти, автоударения и «ё».
- `stt/stt-worker.py` — воркер распознавания: запись с микрофона и локальный faster-whisper (модель в памяти).
- `silero/silero-tts.py`, `silero/compare-models.py` — оставлены, но приложением не используются: разовый синтез Silero и сравнение моделей. На первый указывает ключ `sileroScript` в `config.json` — он ни на что не влияет.
- `sapi/sapi-speak.ps1` — синтез SAPI 5 в отдельном процессе.
- Текст режется по предложениям на куски: первый озвучивается сразу, следующий докачивается, пока звучит текущий. Повторный текст берётся из кэша (ключ — движок, голос, настройки произношения и сам текст; смена скорости плеера кэш не сбрасывает).
- Логи воркеров лежат отдельно от `tts-overlay.log`: `%TEMP%\edge-worker.log` и `stt/stt-worker.log` (см. `docs/adr/0002-worker-logs.md`); у Silero лога нет.
- Папки рядом: `cache/` — озвученные файлы, `spool/` — очередь команд от других программ, `tts-overlay.log` — журнал, `tts-overlay.pid` — номер запущенного процесса.

## Управление из других программ

Пока оверлей запущен, ему можно отдать текст файлом:

```powershell
pwsh -File tts-overlay.ps1 -Say "текст для озвучки"
pwsh -File tts-overlay.ps1 -Clipboard    # озвучить буфер
pwsh -File tts-overlay.ps1 -Stop         # стоп
```

Так ответы агента можно озвучивать автоматически: хук OpenCode кладёт текст в `spool/`, оверлей его читает и произносит.

## Если что-то не так

- Хоткей не срабатывает: клавиши занял другой (приложение). Проверь `tts-overlay.log` на строку «не зарегистрировал» и поменяй комбинацию в `config.json`.
- «Ничего не выделено»: программа не отдала выделение по `Ctrl+C` (например, выделен текст в терминале с другим режимом или в приложении с админ-правами — тогда запусти оверлей тоже от админа).
- Edge молчит: сервис Microsoft периодически перестаёт отдавать звук. Виджет сам переключится на Яндекс; если нужен именно Edge — попробуй позже или выбери другой движок в `⚙`.
- Ошибка TTS: в статусе будет текст ошибки от OpenRouter; бесплатные модели иногда перегружены — попробуй позже или выбери другую модель в `⚙`.
- Платные модели: работают, если на аккаунте OpenRouter есть средства; бесплатная `fish-audio` — 0 ₽, но лимит 1000 запросов в день и без гарантий по задержке.
